# Support

D2L-CLI is maintained on a best-effort basis by one person.

- Setup problems: see the troubleshooting table in the README and `docs/DEVELOPMENT.md`.
- Bugs and questions: open a GitHub issue. Include your D2L-CLI version (`d2l --version`),
  Windows and Python versions, and the exact `error:` line. **Do not paste cookies, course
  content, grades or screenshots.**
- Security issues: do not open a public issue; follow [SECURITY.md](SECURITY.md).
- Your institution's login, MFA, account access and Brightspace outages are not something this
  project can fix; contact your institution's IT help desk.
